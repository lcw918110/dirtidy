完整流程说明

完整流程：扫描（产出候选与待隔离清单）→ 审阅（逐条确认或保留） → 执行（搬进隔离区）→ 确认无误后在隔离区页彻底删除释放空间。 规则命中项永远先搬进隔离区，不会直接删除；只有你在「规则」页显式开启 「直删」的规则，才会在搬入后立刻物理删除。

扫描 第 1 步 · 看看有什么

扫描只读取元数据与内容 hash，不移动、不删除任何文件。 结果会显示在下方，按规则分组，并标出「建议清理 / 可以清理 / 需要你判断」。 看完点「去审阅」逐条判断——「扫描后立即执行自动隔离」是跳过审阅的捷径， 想按流程走就别勾它。

默认设置就够用。想换规则包、调并行线程数，或加额外保护路径，展开下面的「高级选项」。

执行 第 3 步 · 动手

到这一步才会真正搬文件。搬进隔离区（不是删除），随时可还原； 确认无误后再去「隔离区」页彻底删除释放空间。

规则命中的自动隔离

候选的决策

执行按「决策」列搬走隔离 / 归档项；「保留不动」的不碰。

隔离区 第 4 步 · 确认后释放空间

隔离区是中间状态：文件已离开原位但还在磁盘上，占着空间。 确认不需要了就在这一页彻底删除释放空间；发现删错了就还原回原位 （原路径已有文件时会跳过，不覆盖）。彻底删除不可恢复。

这些条目命中了「直删」规则，已搬入隔离区后立刻物理删除，不可还原。

规则 配置

规则动作分三档：protect（永不自动隔离，最高优先级）、 auto_quarantine（进待隔离清单）、candidate_only（只进候选，交人工）。 标了「建议直删」的规则是重建成本为零的类型；勾选「直删」后，它命中的项会 先搬入隔离区、随即物理删除，不再占用空间。保护判定依然优先——直删不会成为绕过保护的缝。

设置 配置

模型分析

模型是可选增强：不用它，规则引擎与人工终审一样完整。 它只对「候选」类文件给建议，且默认只外发安全摘要（可截断的文本片段，密钥会被打码）。

危险操作

彻底删除隔离区条目不可恢复。按条目删除会同步收敛清单；「清空隔离区」等价于 命令行的 dirtidy purge-quarantine --yes。

这些按钮刻意不放在设置页，而是和条目放在一起——你得看着要删的东西再点。

监视 长期运行

监视会定期扫描并报告新增命中，但绝不执行任何隔离—— 它只回答「现在有什么」，动不动是人的决定。命令行等价于 dirtidy watch。
