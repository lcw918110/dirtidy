# dirtidy — 测试与验收

## 1. 平台矩阵

| 平台 | MVP 要求 |
|------|----------|
| macOS | 开发机必测（已跑自动化） |
| Linux | CLI 夹具必测；路径使用 posix 相对路径，与平台无关的用例相同 |
| Windows | 自动化锁定 inventory 路径不含反斜杠；实机 GUI 未在本环境重复 |

三平台由 `.github/workflows/ci.yml` 覆盖（ubuntu / macos / windows × Python 3.11、3.12），
每次 push / PR 跑 `ruff check`、`mypy`、`pytest`。推到 GitHub 后生效。

## 2. 夹具

`tests/fixtures/sample_workspace/`：

- 含 `node_modules/x`、`__pycache__/y`、空目录、`app.log`
- 含内容相同的两份 `dup_a.txt` / `sub/dup_b.txt`
- 含 `payload.txt` 与将其打成 zip 的 `payload.zip`（成员 hash 应匹配）

## 3. 自动化用例

| 用例 | 期望 |
|------|------|
| test_scan_inventory | inventory 含夹具文件 |
| test_apply_rules_quarantine | node_modules 等进入隔离且 manifest 有记录 |
| test_duplicate_candidate | 重复组出现在 candidates |
| test_archive_hash_candidate | payload.zip 因 hash 对照进入候选 |
| test_restore | 还原后原路径文件存在 |
| test_analyze_mock | mock provider 写出 suggestions |
| test_apply_pending | scan 后 apply-rules 隔离 pending auto 命中：`result['quarantined']`≥1 且 node_modules 不再存在 |
| test_apply_decisions_archive_and_quarantine | archived/quarantined/kept 各为 1；archive 落位、被隔离项消失、keep 项仍在 |
| test_inventory_paths_are_posix | 相对路径不含反斜杠 |
| test_sweep_empty_parents_after_move | 日志搬走后空父目录被多轮隔离 |
| test_hash_cache_skips_second_scan | 未改动文件第二次扫描不再算 hash |
| test_purge_requires_yes_then_deletes | 无 `--yes` 不删；有 `--yes` 才清隔离区 |
| test_web_save_and_apply | Web 保存决策并执行隔离 |
| test_openai_compatible_parses_json_array | OpenAI 兼容请求与 JSON 解析 |
| test_ollama_parses_response | Ollama 请求与 JSON 解析 |
| test_archive_member_names_mark_installer | 成员名判定安装包 / 源码快照 |
| test_iter_archive_members_returns_error_for_not_implemented | 加密/坏 zip 使 iter_archive_members 返回错误而非抛异常 |
| test_load_model_config_raises_when_only_example_exists | 仅有 models.example.yaml 时 load_model_config 抛 FileNotFoundError，不静默回退 |
| test_resolve_under_rejects_escape | `..` 逃逸与绝对路径被 `resolve_under` 拒绝，正常相对路径可用 |
| test_decision_path_traversal_blocked | 决策 path 含 `..` 时根外文件不被搬动，且计入 skipped |
| test_archive_target_traversal_blocked | 归档 target_relpath 越界被拒，源文件留在原地 |
| test_apply_decisions_reports_skipped_when_target_exists | 归档目标已存在时计入 skipped 而非静默丢弃 |
| test_analyze_targets_limited_when_no_candidates | candidates 为空集时深层非候选文件不外发 |
| test_summary_skips_sensitive_filenames | 敏感文件名不抽样；含密钥内容被脱敏 |
| test_state_dir_override_relocates_state | 设置 DIRTIDY_STATE_DIR 后状态目录落在外部，目标根不被污染 |
| test_state_dir_creation_failure_gives_actionable_error | 状态目录无法创建时报可操作错误（含 DIRTIDY_STATE_DIR 提示） |
| test_security_headers_present | 审阅页返回严格 CSP 与 `nosniff` |
| test_frontend_avoids_innerhtml | app.js 不再使用 innerHTML（静态守护，防 XSS 回归） |
| test_load_model_config_explicit_path | 显式传入路径时只认该路径 |
| test_load_model_config_respects_dirtidy_config_env | `$DIRTIDY_CONFIG` 优先，不依赖 cwd / 源码树 |
| test_load_model_config_finds_user_config_dir | 非 editable 安装可用 `~/.config/dirtidy/models.yaml` |
