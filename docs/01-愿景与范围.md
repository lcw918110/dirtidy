# dirtidy — 愿景与范围

## 1. 产品定位

`dirtidy` 是跨平台（macOS / Linux / Windows）的**本地目录整理工具**：用可配置规则清理高置信无用物，对残留文件做模型辅助分析，并由人工在可视化界面终审「留 / 隔离 / 归类」。

统一底层引擎；界面为 CLI 与本地 Web，不绑定单一业务场景。

## 2. 典型场景（示例，非产品边界）

- 服务器或工作区长期堆积的依赖缓存、日志、安装包、解压残留压缩包、重复文件、空目录
- 交接或归档前，对「说不清」的大目录做可审计清理与归类建议
- 本机项目目录的周期性整理

## 3. 干系人

| 角色 | 诉求 |
|------|------|
| 运维 / 管理员 | 在服务器上用 CLI 安全扫描与隔离，可回放审计 |
| 业务负责人 | 在本机 Web 上确认残留文件的去留与归类 |
| 工具维护者 | YAML 规则包与模型配置可扩展 |

## 4. MVP 范围（第一期）

**做：**

- 扫描指定根目录，产出 inventory 与审计
- YAML 规则包：高置信项默认进隔离区（quarantine）
- 解压残留（成员内容 hash 对照）、重复文件：默认仅候选，重复由人工选留
- 旁路压缩包：基于内容判定后再标候选
- 可配置 OpenAI 兼容 API 与 Ollama；外发默认安全摘要
- CLI 全流程 + 本地 FastAPI Web 审阅与决策回写

**不做：**

- 桌面原生壳（Electron/Tauri）
- 定时监控 / 文件夹监视
- 无确认的自动彻底删除
- 企业账号体系、多租户
